# News HTML Reader

Windows上で動作するローカルFlaskアプリです。BBC、NAVER NEWS、中央社 CNA の保存済み記事から見出し・本文を抽出し、元ページで使われていた画像も表示します。本文の選択翻訳、単語クリック翻訳、全文翻訳に対応します。

## 起動

1. Windows 10/11で `start_windows.bat` をダブルクリックします。アプリの起動処理は `launcher.py` に集約しています。`.bat`はPython実行環境がないPCで公式インストーラーを取得・SHA-256検証して導入するための最小ブートストラップです。
2. Python 3.10以上が見つからない場合、ブートストラップ版Pythonをユーザー領域へインストールします。続けてこのPC専用の仮想環境を `%LOCALAPPDATA%` 以下に作り、起動のたびにpipの最新版を確認して更新してから依存パッケージを入れます。オフラインなどでpip更新に失敗した場合は、現在のpipで起動を続けます。
3. 接続先は起動時に自動判定します。利用可能なTailscale IPを優先し、なければ有線・Wi-FiのプライベートIPv4を使います。どちらもなければlocalhostのみで待ち受けます。設定済みの範囲から空きポートを選び、表示されたURLを使います。
4. 終了時はコマンド画面で `Ctrl + C` を押します。

初回起動時だけ、待受けIPを固定するか（Tailscale/private IPv4を入力、空欄なら自動判定）、起動後にブラウザーで翻訳設定を開くかを尋ねます。APIキーはコマンド画面には入力せず、ブラウザーの設定画面で登録してください。初回案内は依存関係のセットアップ完了後にこのWindowsユーザーでは再表示しません。記事フォルダはZIPを展開した場所の `articles` です。接続先のIP・ポートやAPIキーは、ブラウザーの「設定」画面から後で変更できます。IPとポートの変更はアプリ再起動後に反映されます。Tailscaleがない場合でもPC上では使えます。スマートフォンから使う場合は、Tailscaleへ接続するか同じ信頼できるLANに接続してください。Windows Firewallの許可状況によってはLANからの接続を許可する必要があります。

Pythonソースの変更時はローカルサーバーが自動で再起動します。テンプレートとCSSはリクエスト時に読み直すため、ブラウザを更新すると反映されます。

## 記事の閲覧

起動するとトップページに、保存済み記事が新しい順のカード（サムネイル・見出し・冒頭文・公開日時）で並びます。上部のチップでサイト別（BBC / CNA / NAVER NEWS など）に絞り込め、検索ボックスで見出しと冒頭文を検索できます。`articles/<サイト名>/` にHTMLを置くとサイト別に分類されます。HTML以外は表示しません。画面の状態はすべてURL（例: `/?source=CNA&page=2`、`/a/42`）に入るため、戻る操作・リロード・ブックマーク・複数端末での利用が同じ動きになります。

記事の見出し・日時・冒頭文は `instance/library.sqlite3` に索引化され（自動取得 `collector.py` は収集の直後にこの索引も更新するので、新着記事は次にトップを開いた時点で表示されます）、HTMLが追加・更新されたものだけが再解析されます（索引は消しても自動で再作成されます）。`HTML_DIRECTORY` 環境変数で記事フォルダの場所を変更できます。なお、以前の「任意フォルダを選択して開く」機能は、URLベースの構成にあわせて廃止しました。

記事を開くと、記事ごとの画像を `<記事ファイル名>_media` フォルダにキャッシュし、本文と一緒に表示します。画像をキャッシュできない場合は、許可済みの元サイト画像URLから表示します。初回は取得中のため時間がかかることがあります。

## 1時間ごとの自動取得

初回起動時に `launcher.py` がWindowsタスクスケジューラへ1時間ごとのタスクを登録し、登録直後に最初の収集も開始します。タスクは独立した `collector.py` プロセスでBBC、NAVER NEWS、中央社CNAの新着記事を確認するため、ブラウザーやWebアプリを開き続ける必要はありません。タスクはコンソールを表示しない `pythonw.exe` で動作し、ログはファイルに記録します。各巡回で各サイト最大3件の新規記事を `articles/BBC`、`articles/NAVER NEWS`、`articles/CNA` に元のHTMLで保存し、記事のcanonical URLが既存なら重複をスキップします。記事画像はHTML取得時には一括保存せず、記事を初めて開いたときに既存の画像キャッシュ処理で保存します。

NAVER NEWSは「設定」画面でNAVER API HUBのClient ID/Secretを登録すると自動取得します。API HUBのニュース検索を検索語「뉴스」、日付順に呼び、結果からNAVERのニュース記事URLを選んでHTMLを取得します。NAVERの記事ページでrobots.txtが取得を許可しない、またはルールを確認できない場合は取得をスキップします。APIキーが未登録の場合もスキップし、`instance/news_autofetch.log` に理由を記録します。NAVER Cloudコンソールで「ニュース検索」APIを有効にしてください。新しくSearch APIを使う場合は[NAVER API HUB](https://api.ncloud-docs.com/docs/naver-api-hub-overview)を利用します。ニュース検索は1日25,000回が上限で、このアプリは最大24回/日です。

取得前に各ホストの `robots.txt` を確認し、取得禁止または確認不能の場合はそのホストをスキップします。ログは `instance/news_autofetch.log` に保存します。タスクは現在のWindowsユーザーがログイン中に、PCが起動している間に実行されます。アプリのブラウザー画面を閉じても収集を続けます。PCが停止・スリープしていた時間に実行できなかった巡回をすべて後から埋め合わせることはしません。タスクは同時に複数の収集が走らないようロックします。CNAのRSS利用規約は非商用利用、出典表示等を定め、RSS自体は見出し・前文・リンク・画像を提供するものと説明しています。保存したHTMLは個人閲覧にとどめ、外部へ再配布しないでください。

## 翻訳・発音・辞書

記事ページの「対訳で読む」を押すと、原文の各段落の直下にその訳文が並び、見出しの訳も表示されます（もう一度押すか翻訳先を変えると閉じます）。段落ごとに別々に翻訳するため原文と訳文が1対1で対応し、翻訳結果は段落バッチ単位でこのPC内にキャッシュされるので、同じ記事を開き直しても再課金されません。訳文の部分は単語クリック翻訳の対象外です。原文の単語は対訳表示中もそのままクリックして調べられます。

記事本文の単語をクリックするとその単語を翻訳します。文章をドラッグして選択すると、選択範囲を翻訳するボタンが表示されます。本文上部の翻訳先メニューから日本語、English (UK)、한국어、繁體中文を選び、「全文を翻訳」で本文全体を訳せます。翻訳先の選択はブラウザ内に記憶されます。

初回は画面上部の「設定」を開き、Azure Translator（F0）またはDeepL APIのキーを登録してください。Azure F0は月次無料枠を使う設定として選べます。Azureアカウント・Translatorリソースの作成後、キーを登録します。地域リソースの場合はリージョン名も入力します。キーを設定しなくても記事の閲覧はできます。

- **Azure Translator**: F0は標準翻訳など合算で毎月200万文字が無料です。無料上限でリクエストは拒否され、S1の有料枠へ自動移行しません。Azure言語表で英語は一般コード `en` のためEnglish UKを明示する翻訳はできません。[料金](https://azure.microsoft.com/en-us/pricing/details/translator/) · [対応言語](https://learn.microsoft.com/en-us/azure/ai-services/translator/language-support) · [REST API](https://learn.microsoft.com/en-us/azure/ai-services/translator/text-translation/reference/v3-0-translate)
- **DeepL API**: 英国英語を `EN-GB` で指定できます。現行Developerプランは合計100万文字まで、Growthは月100万文字を含み超過分は従量課金、Growthの月間上限は5,000万文字です。月次枠を使う場合はGrowth等の月額契約を確認してください。[DeepL APIプラン](https://support.deepl.com/hc/en-us/articles/360021200939-DeepL-API-plans) · [利用量・請求](https://support.deepl.com/hc/en-us/articles/360020685720-Usage-count-and-billing-in-DeepL-API)
- **韓国語の漢字語**: 国立国語院「標準国語大辞典」のOpen APIから、選択語に対応する漢字と韓国語の語義を表示します。APIキーの[利用申請](https://stdict.korean.go.kr/openapi/openApiInfo.do)が必要です。同音異義語が複数ある場合は候補を複数表示し、辞書の出典へリンクします。
- **中国語の注音符号・語義**: 選択文字列の完全一致項目を[教育部《重編國語辭典修訂本》](https://dict.revised.moe.edu.tw/index.jsp)の公開検索ページで調べ、該当する場合は注音と辞典本文の語義を表示します。同辞典に公開JSON APIは確認できなかったため、検索ページと項目ページのHTMLを読み取ります。一致項目がないときは読みや語義を推測しません。
- **英国英語の発音記号**: eSpeak NGを`en-gb`でローカル実行しIPAを生成します。これは辞書の発音を引く方式ではなく、音声エンジンによる発音推定です。頭字語・固有名詞・記事内の特殊な読みは誤ることがあります。

翻訳対象の選択範囲または記事本文は、設定しているAzure TranslatorまたはDeepLへ送信され、翻訳結果はこのPCのSQLiteキャッシュに保存されます。AzureでEnglish (UK)を選ぶと地域指定ができないため、エラーを表示してDeepLを案内します。中国語の辞書照会では選択語を教育部サイトへ、韓国語では選択した語を国立国語院APIへ送ります。英語のIPAはPC内で生成されます。APIキーは画面に再表示せず、Windows資格情報ストアに保管します。設定画面からキーを削除できます。利用条件とプライバシー方針は各サービスの公式サイトで確認してください。

## 対応サイト

- **BBC** 通常記事と動画記事（動画記事は説明文のみ）
- **NAVER NEWS** 本文コンテナ `#dic_area`（`<br>` 区切りを段落化）
- **中央社 CNA** `article.article .centralContent` の本文（関連記事を除外）

サイト側のHTML構造変更、ライブ記事、特集記事等では抽出できない場合があります。動画の字幕・文字起こしは対象外です。

## 技術・安全性

- Flask、BeautifulSoup、eSpeak NG音素エンジンを使用
- Flask単体の安全な既定値は `127.0.0.1:5000` です。`start_windows.bat` は `start_config.bat` の設定を使い、指定したTailscale/private IPでのみ待受けます。
- HTML本文はテキストとして表示し、対象ファイルは最大400件・各12MBです。
- シンボリックリンクとディレクトリ外へのファイル参照を拒否します。
- APIキー以外の設定と翻訳キャッシュは `instance` 以下に保存されます。`instance` はGit対象外です。
- APIキー（Azure、DeepL、国立国語院、NAVER API HUB）はそのPCのWindows資格情報ストアに保存され、フォルダやZIPには入りません。利用者ごとに各自のキーを設定してください。
- 保存済みニュースHTMLと画像には各社の著作物が含まれます。配布用ZIPを作るときは記事HTML・画像、`instance`、仮想環境を除外してください。記事の自動取得は受け取った側のPCで実行できます。
- 本文は保存済みHTMLから読み込みます。画像取得時のみ、BBC・NAVER・CNAの許可済み画像ホストへアクセスします。各サイトの利用規約・著作権に配慮してご利用ください。

## 自宅PCでの個人用アクセス（Tailscale）

インターネットに直接公開せずスマートフォンから使う場合は、自宅PCとスマートフォンにTailscaleを入れ、同じtailnetへログインします。ルーターのポート開放やPublic IPでの公開は不要です。TailscaleのMagicDNSを有効にすると、スマートフォンのブラウザーからサーバー名でアクセスできます。クライアント接続が必要で、Tailscaleにログインした端末だけがtailnet内のサービスへ接続します。

1. サーバーPCとスマートフォンにTailscaleをインストールし、同じtailnetへログインします。
2. `start_windows.bat` を起動します。スクリプトがサーバーPCのTailscale IPを自動で選び、利用可能なポートを表示します。
3. スマートフォンでTailscale VPNをオンにし、起動画面に表示されたURLを開きます。Tailscaleの状態取得ができる場合はMagicDNS名も許可リストへ追加されます。
4. サーバーPCのスリープを無効にし、アプリを起動したままにします。Tailscale管理画面のアクセス制御で、このサービスへ接続できるユーザー・端末も確認してください。

アプリは特定のプライベートIPだけで待受け、`0.0.0.0` には広げません。記事は常に `HTML_DIRECTORY` 以下だけに制限されます。アプリ自体にユーザー認証はないため、信頼できるtailnetまたは自分のLAN内でのみ使ってください。Public IPへのポート転送やTailscale Funnelは有効にしないでください。

### DB・ファイルとCodex CLI

- SQLite、翻訳キャッシュ・月間利用記録、記事HTML・画像はアプリと同じ常時稼働PCのローカルディスクに置きます。スマートフォンはWebアプリへリクエストし、DBファイル自体は開きません。SQLiteファイルをSMBなどのネットワーク共有上に置く必要はありません。
- 月間翻訳利用量は「このアプリからAPIへ送った分」の記録です。キャッシュヒットは数えません。AzureはAPI応答の計上文字数を記録し、応答にない場合は送信文字数を推定値として使います。DeepLは送信文字数の推定で、契約上の正確な残量は各サービスの管理画面で確認します。
- Codex CLIはこのアプリの起動要件ではなく、配布ZIPにも含まれません。使うPCごとに別途導入・サインインしてください。

## 配布用ZIP

`python make_portable_zip.py` を実行すると、アプリ本体だけのZIPをプロジェクトフォルダの隣に作成します。PC固有の仮想環境、接続先上書き設定、設定・翻訳キャッシュ、テスト、保存済みニュースHTMLと画像は含めません。受け取った側はZIPを展開し、`start_windows.bat` を起動してください。翻訳には利用者自身のAPIキーが必要で、スマートフォンからの接続にはそのPCのTailscaleまたは同じ信頼できるLANが必要です。
