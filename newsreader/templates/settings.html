00 · CONNECTION

接続先

現在の接続先: {{ active_bind_host }}:{{ active_port }}。空欄にすると起動時にこのPCのTailscale IP、LANのプライベートIPを自動選択し、ポートも空いている番号から選びます。start_config.batに同じ設定がある場合は、そちらの値が優先されます。

指定できるのはloopback、プライベートIPv4、Tailscale IPv4です。Tailscale IPはそのPCで変わることがあるため、別PCへ移す場合は空欄にして自動検出するか、移動先で設定してください。

IPまたはポートの変更を保存した後はアプリを再起動してください。現在のブラウザー接続は再起動まで維持されます。

01 · NAVER COLLECTION

NAVER NEWSの自動取得

NAVER API HUBのニュース検索で新着記事を見つけ、NAVER記事ページを保存します。APIキーはWindows資格情報ストアに保存され、配布ZIPには含まれません。

NAVER Cloud Console ↗ · API HUBのキー発行方法 ↗ · ニュース検索APIガイド ↗

NAVER Cloudコンソールでアプリケーションを登録し、「ニュース検索」APIを追加して認証情報を入力してください。APIキーが未設定の場合、NAVERの自動取得はスキップされます。毎時、指定した検索語の新着順から最大3件のNAVERニュース記事HTMLを保存します。

04 · PLAN NOTES

料金・上限の比較

Azure Translator

F0には毎月200万文字の無料枠があります。上限を超えた場合はF0でエラーとなり、自動で有料のS1に切り替わりません。AzureアカウントとTranslatorリソースの作成が必要です。English UKは指定できないため、その翻訳にはDeepLを選んでください。

Azure Translator料金 ↗ · 対応言語 ↗

DeepL API

英国英語（EN-GB）を明示できます。現行Developerプランの文字枠は合計枠で、月ごとには戻りません。月次枠が必要な場合はGrowthなど月額プランを確認してください。Growthは月100万文字を含み、超過分は従量課金で、月間利用上限があります。
